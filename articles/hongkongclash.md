# hongkongclash 节点订阅

## 是什么

这是一个免费节点订阅的聚合页面，定期更新，提供 Clash、V2ray、Sing-box、Shadowrocket 等协议的订阅链接。把链接复制进对应客户端，就能直接导入节点列表使用，适合临时、轻量的网络访问需求。

## 订阅链接怎么用

页面上会列出若干订阅链接，按协议分类：

- **Clash 订阅**：`*.yaml` 结尾，导入 Clash 系客户端
- **V2ray 订阅**：`*.txt` 结尾，导入 V2ray 系客户端
- **Sing-box 订阅**：`*.json` 结尾，导入 sing-box

拿到订阅链接后，在客户端的「订阅 / 配置」里粘贴导入即可。

## 支持的客户端

页面整理了一张工具对照表，覆盖主流客户端：

| 协议 | 常见客户端 |
|------|-----------|
| Clash | Clash for Windows、ClashX、Clash for Android |
| V2ray | V2rayN、V2rayNG、Qv2ray |
| Shadowsocks | shadowsocks-win、Shadowrocket、Surge |

## 注意

- 节点爬取自网络，质量不稳定，速度会波动
