# archify

## 解决什么问题

这是一个**帮你画架构图的 skill**。写文档、做汇报、梳理项目结构的时候，经常要画架构图、流程图、时序图。自己画要么太丑、要么太费时间，用专业画图工具又要学一堆操作。

这个 skill 解决的就是这个问题。你只要用自然语言描述"我要画什么"，或者直接给它一段 Mermaid 代码，它就能生成一张**好看的、可交互的 HTML 架构图**，支持明暗主题切换、缩放拖拽，还能导出成 PNG、JPEG、SVG 等格式。

## 工作流程

它的用法很简单：

**1. 告诉它画什么。** 用大白话描述，比如"画一个前后端分离的系统架构图"，或者直接贴一段 Mermaid 代码。

**2. 它选图类型。** 支持 5 种图：架构图、工作流程图、时序图、数据流图、生命周期/状态图，它会根据你的需求自动选最合适的。

**3. 它生成 HTML。** 产出的是一个单文件 HTML，里面有内联 SVG 图，双击就能在浏览器打开，还能切深色/浅色主题、导出图片。

## 使用示例

**例子：画系统架构图**

```
@gateway 用 archify skill 实现 画一个前端 React + 后端 Flask + 数据库的架构图
```

它会生成一张包含前端、后端、数据库组件及其连接关系的交互图，你可以缩放、点选节点看关系。

**例子：把 Mermaid 美化**

```
@gateway 用 archify skill 实现 把这段 Mermaid 时序图美化一下
```

它会把你贴的 Mermaid 代码转成更精美的 HTML 图。
