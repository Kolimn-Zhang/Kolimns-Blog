# ui-ux-pro-max

## 解决什么问题

这是一个**做 UI 设计的 skill**。当你要设计页面、做组件、挑颜色字体、或者检查界面好不好用时，直接找它，它能帮你：

- 给出一套完整的配色方案（具体到每个颜色的色值）
- 推荐合适的字体搭配
- 告诉你界面有哪些问题（比如文字看不清、按钮太小、颜色对比度不够）
- 针对你用的框架（React、Vue、Flutter 等）给具体的写法建议

不用它的话，这些只能凭感觉做，结果经常是颜色乱搭、字体不协调、界面看着不专业。用了它，等于有个懂设计的助手帮你把关。

## 工作流程

它的用法很简单，分两步：

**第一步：告诉它你要做什么。** 比如"帮我设计一个电商首页"，或"帮我看看这个按钮颜色合不合适"。

**第二步：它去自己的数据库里查。** 它内置了 79 种界面风格、192 套配色、74 组字体、119 条设计规范，查完就给你结果：

- 如果是**新项目** → 直接生成一整套设计（颜色 + 字体 + 间距 + 组件怎么排）
- 如果是**具体问题** → 按"先可访问性、再触控、再性能……"的顺序逐条检查，指出哪里不对、怎么改

你也可以自己直接查它的数据：

```bash
python3 scripts/search.py "spa 养生" --domain color    # 查配色
python3 scripts/search.py "科技感" --domain style      # 查风格
```

## 使用示例

**例子：让它给一个新项目设计配色**

```
@gateway 用 ui skill 实现 为我的 SaaS 产品设计一套配色和字体
```

它会直接告诉你：主色用 `#2563EB`（蓝色）、强调色用 `#EC4899`（粉色）、标题用 Space Grotesk 字体、正文用 Inter 字体，还附上按钮、输入框、卡片该怎么写。

**例子：检查界面问题**

```
@gateway 用 ui skill 实现 帮我看看这个登录页有什么问题
```

它会逐条检查，比如"按钮太小了，至少要 44×44 像素才方便点"、"文字和背景对比度不够，看不清"。
