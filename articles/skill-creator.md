# skill-creator

## 解决什么问题

这是一个**教你做 skill 的 skill**。当你想把自己的一套专业知识、工作流程、或者工具用法，封装成一个别人（包括 AI）能直接用的 skill 时，光凭感觉写很容易写得乱七八糟——结构不对、描述不清楚、别人用不起来。

这个 skill 就是解决这个问题的。它把"怎么做好一个 skill"总结成一套标准流程和规范，你只要跟着它走，就能做出结构规范、能被正确触发的 skill。

## 工作流程

它按六步引导你：

**1. 想清楚**：这个 skill 解决什么问题、什么时候该用它。

**2. 规划内容**：确定需要哪些文件——一个 SKILL.md（主入口）+ 若干参考文档 + 可能需要脚本。

**3. 初始化**：用它提供的脚本生成目录骨架。

**4. 写内容**：按规范写清楚"做什么、怎么做"。

**5. 校验**：用校验脚本检查结构有没有问题（比如描述里不能有尖括号）。

**6. 打包**：打成一个 zip，可以分发给别人安装。

## 使用示例

```
@gateway 用 skill-creator skill 实现 创建一个处理 PDF 的 skill
```

它会一步步问你：这个 skill 要处理 PDF 的哪些操作？需要哪些参考文档？要不要脚本？然后带你走完从初始化到打包的全过程。

## 安装

CodeBuddy 内置，无需安装。
