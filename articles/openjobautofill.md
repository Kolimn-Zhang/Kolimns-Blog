# OpenJobAutofill

## 解决什么问题

投简历最烦的就是网申——每家公司招聘系统不一样，姓名、手机号、教育经历、实习经历……一遍遍重复填。这个插件解决的就是这个：

- 你在本机维护一份简历资料
- 打开招聘网站的表单页，点一下 `开始填写`
- 它自动扫描页面，把能确定的字段填进去，其余标成「待处理」让你自己补

重点是：**资料只存在你本机**，不上传云端；AI 只用来理解字段含义，看不到你的具体简历内容。

## 主要功能

- **一键扫描填写**：自动填能确定的字段，绿色 = 已填，橙色 = 待处理
- **本机存储**：简历资料和 API Key 都只在浏览器本地
- **支持多种控件**：输入框、文本域、单选、多选、下拉框、日期
- **可选 AI**：接 OpenAI 兼容 API，帮它理解不同网站五花八门的字段名；不配 AI 也能用本地规则
- **资料面板**：分类查看、搜索、手动复制，处理橙色待处理字段
- **检查更新**：有新版本浏览器图标显示 `NEW`

## 安装

它是浏览器扩展，用开发者模式安装：

1. 下载或 clone 项目到本机
2. 打开 `brave://extensions/` 或 `chrome://extensions/`
3. 开启右上角 `Developer mode`
4. 点 `Load unpacked`
5. 选项目目录 `OpenJobAutofill`

不需要装依赖、不需要构建，加载目录就能用。

## 第一次使用

1. 点扩展图标 → `设置` → `简历资料`，按模块填你的信息
2. 点 `保存资料`（存到本机浏览器扩展存储）
3. 打开招聘网站的简历填写页或申请表页
4. 点扩展图标 → `开始填写`
5. 检查绿色 / 橙色标记，橙色字段手动补
6. 自己确认后手动提交

想先试效果，可以导入项目里的 `sample-profile.json` 示例资料。

## AI 设置（可选）

不配 API 也能用本地规则匹配填写。想让它更好理解不同网站的字段，可以在设置页填自己的 API 配置，支持 OpenAI 兼容接口，也支持自定义 Base URL、路径、模型名。

隐私边界很清楚：AI 请求只含「当前页面字段 + 资料字段名称」，**不含**姓名、手机号、身份证号等具体值，真正的取值和填写都在本机完成。

## 隐私说明

- 简历资料、API Key 只存本机
- 页面脚本只在点扩展操作后注入
- 不会自动点最终提交按钮
- 不会把简历内容发给 AI
