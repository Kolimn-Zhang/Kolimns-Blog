# Prompt Optimizer

## 解决什么问题

这是一个**帮你优化提示词的工具**。很多时候你用 AI 效果不好，不是 AI 不行，而是你的提示词写得不够好——描述太模糊、要求没说清、或者想让 AI 做的太多但没拆开。

这个工具解决的就是这个问题。你把写得不满意的提示词丢进去，它会：

- **一键优化**：自动把你的提示词改得更清晰、更有效，还能多轮迭代
- **测试效果**：改完后用不同模型跑一遍，看看实际效果好不好
- **对比评估**：把几个版本放一起对比，挑出最好的
- **收藏管理**：好用的提示词存起来，下次直接用

## 主要内容

它围绕"优化 → 测试 → 评估 → 沉淀"一条链路设计，核心功能有：

- **智能优化**：支持系统提示词和用户提示词两种优化，可多轮迭代
- **分析评估**：诊断提示词质量、对优化结果评分、多版本对比、智能改写
- **图像生成**：文生图、图生图、风格迁移（支持 Gemini、Seedream、Grok 等）
- **高级测试**：上下文变量批量替换、多轮会话模拟、工具调用（Function Calling）
- **资产管理**：收藏提示词，带版本历史、可复现示例

它支持 OpenAI、Gemini、DeepSeek、Grok、智谱、Ollama 等众多模型，在设置里填 API Key 就能用。

## 使用示例

**例子：优化一个写得太模糊的提示词**

原始："帮我写一篇文章"

优化后大概会变成："你是一名科技领域的专业作者，请写一篇面向普通读者的文章，主题是 XXX，要求 800 字左右，语言通俗易懂，分 3 个小节，每节配一个具体例子。"

**例子：对比两个版本哪个更好**

把提示词 A 和优化后的 B 一起丢进"对比评估"，它会用同一个模型各跑一遍，给你打分，告诉你哪个效果更好。
